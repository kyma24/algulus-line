# Algulus Line

 A personal exploration of algorithms and data structures in competitive programming.

 **Live site:** https://algulus-line.vercel.app

 ## About

 Algulus Line covers a series of "stations", each on a different area of competitive programming.

 Topics include:
 - Basic concepts
- Data structures
- General algorithms
- Mathematics
- Dynamic programming
- Graph theory
- Trees
- Querying

 The content is written in Markdown and loaded from a local data source.

 ## Tech Stack

 - React
- TypeScript
- Next.js
- Markdown
